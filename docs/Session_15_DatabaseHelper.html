1Why I used DatabaseHelper

Before this session, all notes were one JSON string. Every save rewrote the whole list. DatabaseHelper opens notes.db and a notes table. One class holds the SQL. Screens do not write SQL.

Before

SharedPreferences. One key. Rewrite every note as JSON.

After

SQLite rows. Insert, update, or delete only that note.

2What I edited

  1. I added sqflite and path.
  2. I created lib/data/database_helper.dart with a singleton and CRUD.
  3. I pointed the repository at the helper. Save is insert or update one row.
  4. I removed SharedPreferences from startup in main.dart.
