Emit and omit

In Session 14 I shared notes state across screens. After a change I emit a new list. I omit empty notes, unmatched search, and unsaved back.

1What I edited

  1. I put shared notes state in one class the home and editor both use.
  2. I emit with notifyListeners() after save, delete, undo, or search.
  3. The home view watches that state, so the list rebuilds.
  4. I omit a save when title and description are empty, and when I go back without the check.

Today that shared class is NotesController (Session 16). Session 14 is the emit and omit idea.

2Emit and omit on the note screen

Emit

Send the new notes list so the home screen redraws.

Omit

Skip what should not save or show.

On the note screenWhat happens
Press the checkEmit the new or updated note.
Swipe delete or undoEmit the list without that note, or put it back.
Type in searchEmit the query. Omit notes that do not match.
Empty title and descriptionOmit the save.
Back without the checkOmit the draft. Ask “Are you sure?”
