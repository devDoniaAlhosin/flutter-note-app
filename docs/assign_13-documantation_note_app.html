1What I did

  1. I turned the Flutter starter into a Notes app named Notes, with a title and description on every note.
  2. I built the home list and the editor screens so I can add, open, and change notes.
  3. I used Provider (NotesProvider) so the list and the editor share one notes state.
  4. I saved notes on the device with shared_preferences as JSON.
  5. I added search, swipe delete with undo, and a check button to save. Going back asks “Are you sure?”

3File structure

Each file has one job. Screens talk to Provider. Provider talks to the repository.

File What it does
lib/main.dart Starts the app, sets the theme, and wraps the app with ChangeNotifierProvider so every screen can use NotesProvider.
lib/models/note.dart The Note model: id, title, description/content, created time, updated time, and JSON helpers.
lib/data/note_repository.dart Loads and saves the notes list as JSON with shared_preferences.
lib/providers/notes_provider.dart Shared state: add, update, delete, restore, and search. Calls notifyListeners() after a change.
lib/screens/notes_home_page.dart Home screen: note cards, search box, + button, and swipe to delete.
lib/screens/note_editor_page.dart Editor screen: Title and Description fields. Check button saves. Back shows “Are you sure?”
android/.../strings.xml Sets the Android app name to Notes.
docs/assign_13-documantation_note_app.html This HTML documentation page.
