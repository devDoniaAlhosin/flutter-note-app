Notes app

In Session 13 I turned the Flutter starter into a Notes app. I built the home list and the editor. Each note has a title and a description.

1What I edited

  1. I named the app Notes on the launcher and in the app bar.
  2. I built the home screen with a list, search box, and + button.
  3. I built the editor with Title and Description fields.
  4. I save only with the check. Back asks “Are you sure?” if there are unsaved changes.
  5. I can swipe to delete a note, with Undo.

2Features I added

Add

Tap + and fill Title and Description.

Edit

Tap a card to change the text.

Delete

Swipe left, or delete in the editor.

Search

Filter by title or description.

Check save

The check saves. Back does not auto-save.
